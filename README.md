# Coursera-Tesla-and-GameStop-Stock-Revenue-Dashboard
This project contains a Jupyter notebook for the IBM-style stock and revenue dashboard assignment.

## File
- `final_project_stock_dashboard.ipynb`: Answers Questions 1-6 for Tesla and GameStop stock/revenue extraction and visualization.

## What the Notebook Covers

1. Extract Tesla stock data with `yfinance`
2. Extract Tesla revenue data with web scraping
3. Extract GameStop stock data with `yfinance`
4. Extract GameStop revenue data with web scraping
5. Plot the Tesla stock and revenue dashboard
6. Plot the GameStop stock and revenue dashboard

## Requirements

Install these Python packages before running the notebook:

- `pandas`
- `requests`
- `yfinance`
- `beautifulsoup4`
- `plotly`

Example install command:

```bash
pip install pandas requests yfinance beautifulsoup4 plotly
```
